GridLock Documentation

To quickly get started, use the presets - they can be found in the sidebar.

At minimum, each hotkey needs three things: a Key, some Modifiers, and an Action.

Example:

hotkeys:
  - key: 'H'
    modifiers: [ Ctrl, Win, Alt, Shift ]
    action: Help

  - key: 'Backspace'
    modifiers: [ Alt, Shift ]
    action: Revert

  - key: 'N'
    modifiers: [ Alt, Shift ]
    sequence: [ LeftThird, MiddleThird, RightThird ]

  - key: 'C'
    modifiers: [ Alt, Shift ]
    action: Tile
    parameters:
      inlay:
        type: DisplayWidth
        ratio: 975 / 1000
      grid: [ 3, 1 ]
      index: 2
      size: [ 2, 1 ]

Configuration

Key

Keys are any one key on a keyboard. For generic letters and punctuation, you can simply list it as shown above.

So, "A" for the "A" key, "," for the comma key, etc.

For special keys, you must write the full name, as follows:

  • "Backspace", "Tab", "Enter", "Return", "Escape", "Space"
  • "PageUp", "PageDown", "End", "Home"
  • "Left", "Up", "Right", "Down"
  • "Insert", "Delete"
  • "F1" through "F24"

Modifiers

Modifiers are combinations of the four following keys: Ctrl, Win, Alt, & Shift.

You can omit modifier keys, but doing so generally is not recommended.

Action

The following is a list of base actions that GridLock supports:

  • Help - Display a help message
  • Revert - Revert all previous GridLock actions on this window
  • Minimize / Maximize - Minimize or maximize the window
  • Tile - Tile the window into a grid
  • Move / Jump - Move the window within the display, or jump into a different display
  • Increase / Decrease - Change the size of the window
  • Project - Change the display project setting (Primary only, Secondary only, Duplicate, or Extend)

Each action can also be supplied with a nested tree of parameters. These parameters are specific to each action.

Actions

Help

Displays the GridLock Help message.

Revert

Reverts all actions performed on the last active window.

If you switch windows and invoke GridLock, the previous window is not saved.

Minimize

Minimizes the current active window.

Optionally toggles minimize status on a given window.

parameters:
  toggle: boolean

  • Toggle can be true or false.

    When true, if the last active window is minimized, it is restored; otherwise, the next active window is minimized.

Maximize

Maximizes the current active window.

Optionally toggles maximize status on a given window.

parameters:
  toggle: boolean

  • Toggle can be true or false.

    When true, this hotkey will toggle between maximizing and restoring the window. Otherwise, when false, no action is taken when the active window is already maximized.

Tile

Tile the window into a grid layout.

Optionally apply an inlay to the grid layout, allowing your grid to exist in a subsection of the display.

parameters:
  inlay:
    type:      inlaytype
    scalar:    integer or ratio
    ratio:     ratio
    width:     ratio
    height:    ratio
  columns:   integer
  rows:      integer
  index:     integer
  grid:      [ integer, integer (, optional index integer) ]
  width:     integer
  height:    integer
  size:      [ integer, integer ]
  transpose: boolean
  jump:      boolean

  • Inlay describes a subsection of the display the window is currently on.

    • Inputtype is an enumeration which describes how the inlay is calculated. It can be among the following values:

      • None - No inlay applied. The tile action is applied to the display as a whole.
      • Scalar - Inlay is applied as discrete number of pixels.
      • DisplayWidth - Inlay is a ratio of the display's width, applied to both width and height.
      • DisplayHeight - Inlay is a ratio of the display's height, applied to both width and height.
      • Display - Inlay is a ratio of the display's width & height.

    • Scalar is either a integer or ratio of pixels, when the inlay type is scalar. If an integer is passed in, it is duplicated for both axes.

    • Ratio is a ratio using integers, supplied as integer / integer or integer : integer.

    • Width is a ratio which is applied to the width calculation of inlay.

    • Height is a ratio which is applied to the height calculation of inlay.

  • Columns describe how many columns to tile on the display/inlay.

  • Rows describe how many rows to tile on the display/inlay.

  • Index describes which cell (one-indexed) the window will occupy in the grid. So, for example, if the tile grid is 3 wide by 2 tall, index 1 means the top-left, index 3 means the top-right, index 4 means the bottom-left, index 6 means the bottom-right.

  • Grid is a way to combine Columns, Rows, and (optionally) Index as an singular array. If Index is omitted, it defaults to 1 (top-left). Not intended to be used with column or row parameters.

  • Width describes how many tiles wide the window will inhabit - typically just one tile.

  • Height describes how many tiles tall the window will inhabit - typically also just one tile.

  • Size is a way to combine Width and Height into a single array. Not intended to be used with width or height parameters

  • Transpose describes the behavior when the display is taller vertically than horizontally. When true, the columns & rows are swapped, as well as width & height. The inlay is rotated in place.

  • Jump describes the behavior upon repeat Tile actions when the result is exclusive to one display edge. When the aforementioned condition is true, and the setting is true, the window jumps to the nearby display in the corresponding direction.

Move

Move the active window to a given point in the current display.

Optionally allow repeat move hotkeys to jump to the next display in the corresponding direction.

parameters:
  horizontal: integer or ratio
  vertical:   integer or ratio
  jump:       boolean

  • Horizontal is a ratio of the display width at which to center the active window's horizontal axis. If only an integer is passed, the denominator is 1. If the result would place the window out of the display's bounds, it is shifted back inside the display.

  • Vertical is a ratio of the display height at which to center the active window's vertical axis. If only an integer is passed, the denominator is 1. If the result would place the window out of the display's bounds, it is shifted back inside the display.

  • Jump describes the behavior upon repeat Move actions when the result is exclusive to one display edge. When the aforementioned condition is true, and the setting is true, the window jumps to the nearby display in that corresponding direction.

Jump

Move (jump) the active window into another display.

parameters:
  direction: directiontype

  • Direction describes how a window is moved between different displays.

    • Next - Moves the window to the next (right or downmost) display.
    • Previous / Prev - Moves the window to the previous (left or upmost) display.
    • Left - Moves the window to the display to the left.
    • Right - Moves the window to the display to the right.
    • Up - Moves the window to the display above.
    • Down - Moves the window to the display below.

Increase

Increase the size of the active window.

parameters:
  type:   resizetype
  scalar: integer or ratio
  ratio:  ratio
  width:  ratio
  height: ratio

  • Resizetype is an enumeration which describes how the resize amount is calculated. It can be among the following values:

    • Scalar - Applied as discrete number of pixels.
    • DisplayWidth - Ratio of the display's width, applied to both width and height.
    • DisplayHeight - Ratio of the display's height, applied to both width and height.
    • Display - Dual-ratio of the display's width & height individually.
    • WindowWidth - Ratio of the window's width, applied to both width and height.
    • WindowHeight - Ratio of the window's height, applied to both width and height.
    • Window - Dual-ratio of the window's width & height individually.

  • Scalar is either a integer or ratio of pixels, when the resize type is scalar. If an integer is passed in, it is duplicated for both axes.

  • Ratio is a ratio using integers, supplied as integer / integer or integer : integer.

  • Width is a ratio which is applied to the width calculation of dual-ratio resize.

  • Height is a ratio which is applied to the height calculation of dual-ratio resize.

Decrease

Decrease the size of the active window.

Optionally 'edgelock' the active window such that edges of the window which intersect the edges of the display are not affected.

parameters:
  type:     resizetype
  scalar:   integer or ratio
  ratio:    ratio
  width:    ratio
  height:   ratio
  edgelock: boolean
  restore:  boolean

  • Resizetype is an enumeration which describes how the resize amount is calculated. It can be among the following values:

    • Scalar - Applied as discrete number of pixels.
    • DisplayWidth - Ratio of the display's width, applied to both width and height.
    • DisplayHeight - Ratio of the display's height, applied to both width and height.
    • Display - Dual-ratio of the display's width & height individually.
    • WindowWidth - Ratio of the window's width, applied to both width and height.
    • WindowHeight - Ratio of the window's height, applied to both width and height.
    • Window - Dual-ratio of the window's width & height individually.

  • Scalar is either a integer or ratio of pixels, when the resize type is scalar. If an integer is passed in, it is duplicated for both axes.

  • Ratio is a ratio using integers, supplied as integer / integer or integer : integer.

  • Width is a ratio which is applied to the width calculation of dual-ratio resize.

  • Height is a ratio which is applied to the height calculation of dual-ratio resize.

  • Edgelock describes the behavior when a given edge of the window touches the edge of the display it is on. When true, such edges remain locked to the display edge and are not decreased.

  • Restore describes the behavior when decreasing from a maximized window. When true, the prior window's size is restored; otherwise, the window is set to the maximum window size without being maximized.

Project

Change the display project mode of the operating system.

parameters:
  project: projecttype
  mode:    projecttype

  • Project / mode describes your intended display configuration.

    • Primary / Main - Use only your primary display.
    • Duplicate - Duplicate your primary display across all other displays.
    • Extend - Extend your display space across all other displays.
    • Secondary / External - Use only your secondary or external display.

Sequences

Sequence Hotkeys are also supported by GridLock. Sequences are a series of window actions which are progressed through on repeat presses of the hotkey keybind.

If only preset window actions are used, you can simply use an array:

sequence: [ action, action, ... ]

If instead you want to customize any or each of the window actions inside the sequence, you can:

sequence:
  - action: ...
    parameters:
      parameter: ...
  - action: ...

Regular actions and sequence actions are treated identically, and follow the same parameters as listed here above in the documentation.

Extras

GridLock contains some extra configuration settings, as below.

Minimum

Minimum describes the smallest acceptable window size when performing Decrease operations.

This to ensure your window cannot collapse into nothing.

minimum:
  width:  integer
  height: integer

Units are in pixels.

Borders

GridLock contains some border configurations you can use. There are three options:

borders: invisible, visible, or full

  • Invisible — Attempts to maximize screen real estate. This is the default option.

  • Visible — Attempts to maximize screen real estate while leaving a visible border sliver.

  • Full — Ensures all window edges are fully visible. This uses more screen space and is not recommended.

Enable / Disable

GridLock allows you to enable or disable specific hotkeys or blocks of hotkeys.

By default, all hotkeys are enabled.

  • enable: below - Enables this hotkey and all hotkeys below it.
  • disable: below - Disables this hotkey and all hotkeys below it.
  • enable: this - Enables only this hotkey, overriding any surrounding disable/enable behavior.
  • disable: this - Disables only this hotkey, overriding any surrounding disable/enable behavior.

Note that any new enable / disable entry overrides any previous entry.

  index:     unset
  width:     1
  height:    1
  transpose: false
  jump:      true

  edgelock: true
  restore:  false

    action: Project

  mode: unset

    Initializes a blank or placeholder Project action. You are expected to pass your intended mode in the parameters.
